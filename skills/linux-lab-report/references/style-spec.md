## 字体

正文 run 的字体设置（四种属性都要写，缺一个就会在某些字符上掉字体）：

```xml
<w:rFonts w:ascii="Consolas" w:hAnsi="Consolas" w:eastAsia="仿宋" w:cs="Consolas"/>
<w:sz w:val="21"/><w:szCs w:val="21"/>
```

- `ascii` / `hAnsi` / `cs` = **Consolas**：英文、数字、命令用等宽字体，学生能看清空格和标点。
- `eastAsia` = **仿宋**：正文中文。
- `sz` = **21**（半磅，即 10.5pt）：正文标准字号。

标题和站点小标题的 `eastAsia` 换成 **华文中宋**，并加 `<w:b/>` + `<w:bCs/>`。

大标题（`Linux实验主题`）用 `sz=36`（18pt），华文中宋，不加粗。

> 注意：`w:eastAsia` 影响中文，`w:ascii` 影响英文。报告里中英混排（如 `输入 ps -ef —— 列出所有进程`），一段里两种字体同时生效是正常的，不要试图统一成一种。

## 颜色

| 常量 | 值 | 用途 | 形式 |
|---|---|---|---|
| `K` | `000000` | 正文、标题 | 常规 |
| `G` | `00B050` | 命令 | 行内，与说明文字同段 |
| `Y` | `92D050` | 【截图占位符】 | 居中斜体 |
| `GY` | `808080` | 截图要求、表格边框、实验体会引导语 | 斜体（引导语除外） |
| `BL` | `0070C0` | 【提示】【正确】、实验体会问题 | 常规 |
| `RD` | `C00000` | 【注意】【错误】 | 常规 |

颜色写成 `<w:color w:val="00B050"/>`。

**`w:color` 必须插在 `w:rPr` 的正确位置**。`w:rPr` 的子元素顺序是固定的（OOXML schema 要求），顺序错了 Word 会报「文档已损坏」。正确顺序中 `color` 在 `rFonts`/`b`/`i` 之后、`sz` 之前：

```
rStyle → rFonts → b → bCs → i → iCs → ... → color → ... → sz → szCs → ...
```

`scripts/labdocx.py` 的 `set_color()` 用 `RPR_ORDER` 列表按这个顺序插入，不要绕过它直接 append。

## 段落规格

| 元素 | pPr | rPr |
|---|---|---|
| 一/二/三/四 标题 | `spacing line=360` | 华文中宋，加粗 |
| 实验目的条目 | `pStyle=a9` + `numId=5` + `ind firstLineChars=0` | 仿宋 |
| 实验设备条目 | `pStyle=a9` + `numId=6` + `ind firstLineChars=0` | 仿宋 |
| 实验步骤标题 | `pStyle=a9` + `numId=7` + `ind firstLineChars=0` + `spacing line=360` | 华文中宋，加粗 |
| 引言段 | `jc=both` + `ind firstLineChars=200` | 仿宋 |
| 速查卡/命令表标题 | `jc=center` + `spacing line=360` | 仿宋 |
| 站点标题 | `jc=both` + `spacing line=360` | 华文中宋，加粗 |
| 编号任务 | `numId=3` + `jc=both` + `spacing line=360` | 仿宋 |
| 命令行 | `pStyle=a9` + `numId=4` + `ind firstLineChars=0` | 仿宋 |
| 提示/正确/注意/错误 | `ind left=420` | 仿宋，按语义着色 |
| 截图要求 | `ind left=420` | 仿宋，灰，斜体 |
| 截图占位符 | `jc=center` | 仿宋，浅绿，斜体 |
| 空行 | `jc=center` + `spacing line=360` | — |
| 教师签名/日期 | `jc=right` + `spacing line=360` | 仿宋 |

`line=360` 是 1.5 倍行距（240 = 单倍）。

`ind left=420` 让提示类文字**比正文缩进一格**，视觉上从正文里分开——学生扫一眼就知道「这条是给我的说明，不是要做的事」。

## 编号定义

`numbering.xml` 里 7 个 numId 各有用处。ilvl 0 的定义：

| numId | abstractNumId | numFmt | lvlText | start | ind |
|---|---|---|---|---|---|
| 3 | 0 | decimal | `%1.` | 1 | left=425 hanging=425 |
| 4 | 4 | bullet | `` (Wingdings) | 1 | left=860 hanging=440 |
| 5 | 6 | decimal | `%1.` | 1 | left=440 hanging=440 |
| 6 | 2 | decimal | `%1.` | 1 | left=440 hanging=440 |
| 7 | 5 | japaneseCounting | `%1、` | **3** | left=495 hanging=495 |

- **numId 3**：站点内编号任务，每个站点从 1 重新开始。
- **numId 4**：命令行项目符号（实心小方块）。这是「子项」，所以缩进比 numId 3 深。
- **numId 5**：实验目的，渲染成 `1. 2. 3.`
- **numId 6**：实验设备及环境，同上。
- **numId 7**：实验步骤大标题，`japaneseCounting` + `start=3` → 渲染成 **「三、」**。因为「一、实验目的」「二、实验设备及环境」是手写的，实验步骤正好是第三节。

> 为什么 numId 7 要从 3 开始：如果不这么做，「实验步骤」就得手写「三、」，而它同时又是列表项，用手写序号会破坏缩进一致性。让编号系统直接产出「三、」最干净。这个设计很隐晦——如果你要新增一个同级大标题，记得同步调整 `start`。

**每站重新开始编号**：靠 pPr 里的 numPr 引用同一个 numId 3，Word 会连续编号。要让每个站点从 1 重来，需要在站点标题处插入 `<w:numPr>` 的重启标记。当前模板的做法是——站点标题用的是普通段落（不是列表项），Word 遇到非列表段落就重置计数，所以每站自然从 1 开始。**不要给站点标题加 numPr**，否则整篇会连号。

## 表格

### 外层模板表格

4 行，9 列，跨列合并后显示为 5 列：

| 行 | 内容 |
|---|---|
| 0 | 课程名称 \| Linux操作系统配置与管理 \| 实验项目 \| 实验报告 N + 项目名 \| 实验项目类型（跨 5 列） |
| 1 | 表头占位 \| 验证 \| 演示 \| 综合 \| 设计 \| 其他 |
| 2 | 指导教师 \| 何康健 \| 成绩 \| \| \| \| √ \| \| |
| 3 | **跨 9 列** —— 正文全部内容 |

正文在 `tables[0].rows[3].cells[0]` 这个合并单元格里。**所有正文段落必须在这个单元格内**，否则会跑到表格外面。

边界：`single` / `sz=4` / `color=auto`。

### 三张内容表

| 表 | 行数（含表头） | 表头 |
|---|---|---|
| 速查卡 | 6 | 你熟悉的（Windows）\| 对应的（Linux）\| 关键差异 |
| 常用命令 | 10 | 命令 \| Windows 里对应什么 \| 作用 |
| 报错速查 | 6 | 报错提示 \| 真实含义 \| 怎么办 |

- 边框：六个方向都是 `single` / `sz=4` / `color=808080`。
- 表头行：单元格底纹 `<w:shd w:val="clear" w:fill="E2EFDA"/>`，文字仿宋加粗。
- 数据行：段落 `spacing line=260`（约 1.08 倍），仿宋。
- 宽度：`tblW w=5000 type=pct`（占满可用宽度）。
- 列宽：速查卡三列大致等宽；命令表和报错表第一列窄一些。

行数可变——`scripts/labdocx.py` 的 `fit_rows()` 会克隆最后一行来增加行数，克隆出来的行自动带上边框和字体。

## 页面与页眉

- 纸张：`6624955 x 9361170` EMU（A4，210×297mm）
- 页边距：上下 914400 EMU（2.54cm），左右 1141095 EMU（约 3.17cm）
- 页眉：居中「《Linux操作系统配置与管理》实验报告书」，带下边框（`single` `sz=6`），`sz=18`（9pt）

页眉文字用「华文中宋」，`ascii` 也是华文中宋（不是 Consolas）——这是页眉独有的，正文里的英文一律 Consolas。

## 常见格式故障

| 现象 | 原因 | 处理 |
|---|---|---|
| Word 报「文档已损坏」 | `w:color` 插错位置 | 用 `set_color()`，别手动 append |
| 站点标题丢了加粗 | 用 `rewrite(run_idx=0)`，取到「（」run 的格式 | 改用 `settext()`，它保留最后一个 run |
| 中文掉了字体 | 只设了 `ascii` 没设 `eastAsia` | 四种属性都写 |
| 编号错乱 | 给站点标题加了 `numPr` | 站点标题不加 numPr |
| 正文跑到表格外 | 段落插到了外层表格之外 | 确认插在 `rows[3].cells[0]` 里 |
